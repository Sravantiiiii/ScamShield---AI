# ScamShield AI

AI-powered scam detection tool that analyzes suspicious messages and helps users identify potential scams.

## Problem
People receive suspicious messages through SMS, WhatsApp, email, and social media but may not recognize scam warning signs.

## Solution
ScamShield AI analyzes a message and provides:
- Risk percentage
- Scam type
- Red flags
- Explanation
- Safety advice

## Technologies
- Google Gemini AI
- Google AI Studio
- React
- TypeScript
- Vite
- GitHub

## How It Works
1. Paste a suspicious message.
2. Click Analyze Message.
3. Gemini AI analyzes the message.
4. View the risk assessment and safety recommendations.

## Security
The Gemini API key is stored as an environment secret and is not included in the source code.

## Future Scope

- Voice input
